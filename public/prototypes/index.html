Dashboard

Flexible dashboard

Arrange your dashboard the way you work. Drag a block to move it or drag its corner to resize it; only the blocks in the way make room, so nothing else jumps around. Prefer clicking? Click a block’s grip, then click where it should go. Add blocks from the block browser straight into the space you choose. Changes save as you go, and a removed block is one Undo away. Works with a mouse, touch or the keyboard alone. Switch between a student, teacher and administrator, and see each one’s dashboard today, in phase 2, and in the end state.

User

User profile

/user/profile.php, which is currently a link farm: on a stock site the “User details” card holds an Edit link, an email address and a timezone, while a teacher gets seven near-empty cards stacked in an 830px column. Identity-first header, the bio given a home, staff tooling collected into one panel the student can’t see, and a privacy strip so you can tell what others see. Switch viewer (own / peer / teacher / admin / no access) and flip between Today and New; the Today node lists are dumped from the running site, not invented.
